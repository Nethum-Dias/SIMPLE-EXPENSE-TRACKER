# SIMPLE-EXPENSE-TRACKER
Expense Tracker
A simple Expense Tracker built using Python. This application helps users manage their personal finances by recording income and expenses and tracking their current balance.

Features
 
 1. Add income

 2. Add expenses

 3. View current balance

 4. View all transactions



Requirements

  Python 3.x


How to Run

 1. Download  this repository.

 2. Open the project using any Python IDE or code editor such as VS Code, PyCharm, or any other Python editor.

3.  Run the Python file to start the application.


Purpose

This project was created as a beginner Python project to practice programming concepts such as variables, lists, functions, loops, and user input while building a practical personal finance application.

A simple expense tracker built using Python to record and manage daily expenses. Also for have good financial discipline.
